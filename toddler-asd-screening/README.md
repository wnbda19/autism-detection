# Toddler ASD Screening

A client-side Q-CHAT-10 screening tool for toddlers aged 18–72 months.

## Stack

- React + TypeScript (Vite)
- Tailwind CSS v4
- motion/react for page transitions
- lucide-react for icons

## Run

```bash
cd toddler-asd-screening
npm install
npm run dev
```

## Flow

Welcome → Demographics → 10 Questions → Results

All data stays in the browser; nothing is sent to a server.
